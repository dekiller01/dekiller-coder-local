# Dekiller Coder Local

Asistente de programación local desarrollado con Node.js,
integrado con Ollama y modelos como Qwen3.

## Requisitos

- Node.js 20 o superior
- Ollama instalado y ejecutándose
- Un modelo compatible descargado en Ollama

## Instalación

1. Clona este repositorio.
2. Revisa la configuración de `.env.example`.
3. Ejecuta `npm start`.

## Comprobación

```bash
npm run check
```

## Estado

Proyecto personal en desarrollo. La compatibilidad y las
funciones disponibles dependen de la configuración local.

## Seguridad

No publiques claves, tokens, conversaciones ni datos privados.
